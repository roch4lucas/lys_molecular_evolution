

# Lysozyme molecular evolution in flies and insects data

This repository contains datasets and scripts used in the manuscript
“*Lysozyme molecular evolution in insects reveals feeding habit
adaptations in brachyceran flies*”.

## Files

- **`01_sequences`**: recovered lysozyme gene sequences for
  Calliphoridae and insect annotated genomes, including NCBI gene
  acessions. Also contains the python script `get_biggest_geneids.py`
  used to recover annotated genes from insect reference genomes;

- **`02_iqtree`**: MSAs and iqtree outputs for Calliphoridae C-type
  lysozymes and insecta lysozymes trees;

- **`03_phylo_stats`**: data and R scripts used in phylogenetic
  comparative analyses;

- **`04_selection_analyses`**: MSAs, trees and outputs used and
  generated by CodeML and RELAX selection analyses.

------------------------------------------------------------------------

### **`get_biggest_geneids.py`**

This python script recover the longest isoform of each gene based on a
NCBI GeneID table (.tsv file with species names and it’s corresponding
annotated genes GeneID), generating a fasta file. It attempts to exclude
pseudogenes based on NCBI gene names, descriptions and qualifiers to
such.

The GeneID table can be obtained in the [NCBI Gene
database](https://www.ncbi.nlm.nih.gov/gene/), by filtering for a
specific gene name in a group of organisms. In the case of this
research, we searched for “*Lysozyme AND Insecta NOT uncharacterized NOT
peptidoglycan NOT binding NOT factor NOT subunit*”, filtering for
protein-coding genes.

It is recommended to first filter the Gene table as dubious or spurious
annotations may be found. Then, this script can be correctly used.
